# quiz-battle

내 컴퓨터에서 서버를 켜고, 같은 와이파이에 있는 사람들이 스마트폰 브라우저로 접속해
동시에 퀴즈를 푸는 로컬 멀티플레이 퀴즈 배틀 게임.

- 게임 화면(UI)은 전부 일본어다 (실제 플레이어인 아이들이 일본어만 하기 때문)
- 算数・数学・英語・国語 문제를 풀어 점수를 얻고 (정답 +100, 속도 보너스, 콤보 보너스)
- 3연속 정답마다 아이템을 얻어 상대를 지정해 공격·방해하고
  (흔들기 / 동결 / 가리기 / 뒤집기, 방어용 실드, 자기용 힌트)
- 상대의 진행 상태(몇 번 문제, 몇 점)를 실시간으로 확인한다
- 입장할 때 프리셋 캐릭터 8종 중 하나를 고르거나, 내 사진으로 커스텀 캐릭터를 만들 수 있다

## 실행 방법

필요한 것: Python 3.10 이상이 설치된 호스트 PC 1대, 같은 와이파이에 연결된 스마트폰.

```bash
pip install -r requirements.txt
python server.py
```

서버를 실행하면 터미널에 접속 주소와 QR 코드가 표시된다.

1. 호스트 PC 브라우저로 표시된 주소(예: `http://192.168.0.10:8000/`)를 연다
2. 닉네임과 캐릭터를 정하고 **방 만들기** → 방 코드 4자리가 나온다
3. 다른 사람들은 폰으로 QR을 스캔하거나 주소로 접속해, 닉네임·캐릭터를 정하고
   방 코드로 **입장**한다
4. 방장이 과목(算数・数学/英語/国語)과 레벨을 고르고 **게임 시작**을 누르면 전원 동시 시작

## 레벨

레벨은 방 전체가 아니라 **참가자마다 따로** 지정한다. 방장이 대기실에서 각 참가자
이름 옆의 선택 상자로 레벨을 바꾸면, 그 사람에게는 자기 레벨 문제만 출제된다
(실력이 다른 아이들이 함께 놀 때 각자 맞는 난이도로 겨룰 수 있게).
「レベル（全員まとめて）」는 전원을 한 번에 바꾸는 일괄 지정이고, 새 참가자는
방의 기본 레벨로 시작한다. 손님 화면에는 각자 자기 레벨이 표시만 된다.
점수 규칙(+100, 속도·콤보 보너스)은 레벨과 무관하게 모두 같다.

- **小学5年 (shou5)** — 기본값. 산수는 음수 없는 사칙연산·동분모 위주 분수·소수 1자리,
  영어는 기본 단어, 국어는 小学校で習う漢字の読み와 쉬운 숙어
- **中学1年 (chuu1)** — 음수 포함 사칙연산, 이분모 분수 사칙, 소수 연산,
  학교 영어 단어, 漢字の読み(音読み 함정 포함)와 숙어·격언
- **一般 (ippan)** — 세 자리 덧셈·뺄셈, 두 자리×두 자리 곱셈, 분수 곱셈·나눗셈,
  일반 어휘, 難読漢字와 四字熟語

> 폰에서 접속이 안 되면 호스트 PC의 방화벽에서 8000번 포트 인바운드가 막혀 있는지
> 확인한다. Windows라면 처음 실행할 때 뜨는 방화벽 허용 팝업에서 허용하면 된다.

## 게임 규칙 요약

- 한 판 20문제, 전원 같은 문제 세트, 각자 자기 속도로 풀이
- 정답 +100점, 빨리 맞힐수록 속도 보너스(최대 +50), 연속 정답 콤보 보너스
- 3연속 정답마다 랜덤 아이템 1개. 공격 아이템은 누른 뒤 화면 위쪽의 상대를 탭해서 사용
- 승리: 점수가 가장 높은 사람 (동점이면 먼저 완주한 사람)
- 자세한 기획은 [PLAN.md](PLAN.md)

## 설정 바꾸기

점수, 문제 수, 아이템 효과 시간 같은 모든 게임 수치는 `config.json`에 있다.
서버를 재시작하면 반영된다.

## 문제 추가하기

영어·국어 문제는 코드 수정 없이 파일만으로 추가할 수 있다.

- `data/questions_en.json`, `data/questions_ja.json`
- 형식: `{"question": "문제", "choices": ["선택지1", "선택지2", "선택지3", "선택지4"], "answer": "정답 선택지", "level": "shou5"}`
- `level`은 `shou5`(小学5年) / `chuu1`(中学1年) / `ippan`(一般) 중 하나. 게임은 방장이
  고른 레벨의 문제만 출제한다 (레벨 문제가 20개보다 적으면 중복을 허용해 채운다)
- 산수·수학 문제는 서버가 레벨별 설정(`config.json`의 `math_by_level`)으로 자동 생성한다
- 국어 문제 일부는 JMdict·KANJIDIC2(EDRDG, CC BY-SA 4.0)에서 자동 생성했다.
  생성 파이프라인은 `tools/question-bank/`, 출처·라이선스 표기는
  [tools/question-bank/CREDITS.md](tools/question-bank/CREDITS.md)를 본다.

## 로컬 캐릭터 폴더 (집 안에서만 쓰는 이미지)

유명 캐릭터 이미지처럼 GitHub에 올리면 안 되는 그림은, 호스트 PC의
`local_characters/` 폴더에 넣으면 입장 화면의 「このPCのキャラ」에 뜨고
프리셋처럼 눌러 고를 수 있다. 이 폴더는 `.gitignore`에 들어 있어
**절대 GitHub에 올라가지 않는다.** 서버를 실행하면 터미널 배너에도 폴더
경로가 표시된다. (png/jpg/gif/webp 지원)

## 게임 중 조작

- **一時停止 (일시정지)** — 호스트 전용. 전원의 문제 타이머까지 함께 멈추고,
  재개하면 멈춘 시간만큼 타이머가 밀려 속도 보너스가 깎이지 않는다.
  호스트 접속이 끊긴 동안에는 다른 사람이 재개할 수 있다
- **ゲーム終了 (즉시 종료)** — 호스트 전용. 지금 점수 그대로 결과를 확정한다
- **リタイア (기권)** — 누구나 가능. 결과에 남되, 점수와 무관하게 완주자보다
  뒤 순위가 되고 우승으로 치지 않는다
- **退出 (퇴장)** — 로비·결과 화면에서는 방에서 완전히 나가고, 방장이 나가면
  다음 사람이 방장이 된다. 게임 중 퇴장은 기권으로 처리된다
- 종료·기권·퇴장 버튼은 실수 방지로 한 번 누르면 「本当に？」로 바뀌고,
  한 번 더 눌러야 실행된다

## 소리와 연출

- 시작 카운트다운(3·2·1·GO), 정답 콤보가 쌓일수록 올라가는 음정, 아이템별
  효과음, 우승 팡파레, 게임 중 BGM — 전부 WebAudio 합성이라 음원 파일이 없다
- 정답 시 점수가 떠오르고, 아이템 획득·우승 때 종이꽃가루가 터진다
- 오른쪽 위 🔊 버튼으로 전체 소리를 켜고 끌 수 있다 (설정은 폰에 저장됨)
- 카운트다운 시간(2.4초)만큼 서버가 첫 문제 타이머를 늦춰, 연출 때문에
  속도 보너스가 깎이지 않는다

## 누적 랭킹

판이 끝나면 결과가 `results.sqlite3`에 저장되고, 입장 화면의
**누적 랭킹 보기**에서 승수·누적 점수를 확인할 수 있다.

## 집 밖에서 접속하기 (Tailscale, 선택)

기본 구조는 같은 네트워크 전용이다. 외부에서 접속하려면 공개 인터넷에 포트를
직접 열지 말고 Tailscale을 쓴다.

1. 호스트 PC와 접속할 폰에 Tailscale을 설치하고 같은 계정(tailnet)으로 로그인
2. PC의 Tailscale IP(예: `100.x.x.x`)를 확인
3. 평소대로 `python server.py` 실행 후, 폰에서 `http://<PC의 Tailscale IP>:8000/`으로 접속
4. 방 코드 입장은 LAN에서와 동일

## 테스트

서버를 테스트 포트로 띄운 뒤 스모크 테스트로 한 판 전체를 자동 검증할 수 있다.

```bash
QB_PORT=8765 python server.py   # 별도 터미널에서
python tests/smoke_test.py http://127.0.0.1:8765
```
