# quiz-battle

내 컴퓨터에서 서버를 켜고, 같은 와이파이에 있는 사람들이 스마트폰 브라우저로 접속해
동시에 퀴즈를 푸는 로컬 멀티플레이 퀴즈 배틀 게임.

- 수학·영어·일본어 문제를 풀어 점수를 얻고 (정답 +100, 속도 보너스, 콤보 보너스)
- 3연속 정답마다 아이템을 얻어 상대를 지정해 공격·방해하고
  (흔들기 / 동결 / 가리기 / 뒤집기, 방어용 실드, 자기용 힌트)
- 상대의 진행 상태(몇 번 문제, 몇 점)를 실시간으로 확인한다
- 입장할 때 프리셋 캐릭터 8종 중 하나를 고르거나, 내 사진으로 커스텀 캐릭터를 만들 수 있다

## 실행 방법

필요한 것: Python 3.10 이상이 설치된 호스트 PC 1대, 같은 와이파이에 연결된 스마트폰.

```bash
pip install -r requirements.txt
python server.py
```

서버를 실행하면 터미널에 접속 주소와 QR 코드가 표시된다.

1. 호스트 PC 브라우저로 표시된 주소(예: `http://192.168.0.10:8000/`)를 연다
2. 닉네임과 캐릭터를 정하고 **방 만들기** → 방 코드 4자리가 나온다
3. 다른 사람들은 폰으로 QR을 스캔하거나 주소로 접속해, 닉네임·캐릭터를 정하고
   방 코드로 **입장**한다
4. 방장이 과목(수학/영어/일본어)을 고르고 **게임 시작**을 누르면 전원 동시 시작

> 폰에서 접속이 안 되면 호스트 PC의 방화벽에서 8000번 포트 인바운드가 막혀 있는지
> 확인한다. Windows라면 처음 실행할 때 뜨는 방화벽 허용 팝업에서 허용하면 된다.

## 게임 규칙 요약

- 한 판 20문제, 전원 같은 문제 세트, 각자 자기 속도로 풀이
- 정답 +100점, 빨리 맞힐수록 속도 보너스(최대 +50), 연속 정답 콤보 보너스
- 3연속 정답마다 랜덤 아이템 1개. 공격 아이템은 누른 뒤 화면 위쪽의 상대를 탭해서 사용
- 승리: 점수가 가장 높은 사람 (동점이면 먼저 완주한 사람)
- 자세한 기획은 [PLAN.md](PLAN.md)

## 설정 바꾸기

점수, 문제 수, 아이템 효과 시간 같은 모든 게임 수치는 `config.json`에 있다.
서버를 재시작하면 반영된다.

## 문제 추가하기

영어·일본어 문제는 코드 수정 없이 파일만으로 추가할 수 있다.

- `data/questions_en.json`, `data/questions_ja.json`
- 형식: `{"q": "문제", "choices": ["선택지1", "선택지2", "선택지3", "선택지4"], "a": "정답 선택지"}`
- 수학 문제는 서버가 자동 생성한다

## 누적 랭킹

판이 끝나면 결과가 `results.sqlite3`에 저장되고, 입장 화면의
**누적 랭킹 보기**에서 승수·누적 점수를 확인할 수 있다.

## 집 밖에서 접속하기 (Tailscale, 선택)

기본 구조는 같은 네트워크 전용이다. 외부에서 접속하려면 공개 인터넷에 포트를
직접 열지 말고 Tailscale을 쓴다.

1. 호스트 PC와 접속할 폰에 Tailscale을 설치하고 같은 계정(tailnet)으로 로그인
2. PC의 Tailscale IP(예: `100.x.x.x`)를 확인
3. 평소대로 `python server.py` 실행 후, 폰에서 `http://<PC의 Tailscale IP>:8000/`으로 접속
4. 방 코드 입장은 LAN에서와 동일

## 테스트

서버를 테스트 포트로 띄운 뒤 스모크 테스트로 한 판 전체를 자동 검증할 수 있다.

```bash
QB_PORT=8765 python server.py   # 별도 터미널에서
python tests/smoke_test.py http://127.0.0.1:8765
```
