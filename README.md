# quiz-battle

내 컴퓨터에서 서버를 켜고, 같은 와이파이에 있는 사람들이 스마트폰 브라우저로 접속해
동시에 퀴즈를 푸는 로컬 멀티플레이 퀴즈 배틀 게임.

- 수학·영어·일본어 문제를 풀어 점수를 얻고
- 연속 정답으로 아이템을 얻어 상대를 지정해 공격·방해하고
- 상대의 진행 상태(몇 번 문제, 몇 점)를 실시간으로 확인한다

## 상태

기획 단계 (Phase 0). 자세한 기획과 단계 계획은 [PLAN.md](PLAN.md)를 본다.

## 실행 방법 (예정)

서버는 호스트 PC에서 Python으로 실행하고, 접속용 QR 코드가 표시되면
스마트폰으로 스캔해서 닉네임만 입력하면 입장한다. 앱 설치는 없다.
